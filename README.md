## Overview
This repository contains my final project for AAI201, which predicts soccer match outcomes (Home Win, Draw, or Away Win) using machine learning. The project includes data preprocessing, feature engineering based on pre-match team statistics, training and comparing four classification models, and a reflection on the results.

## Files
- `soccer_match_prediction.ipynb` — Main notebook with all project parts
- `soccer_prediction_presentation.pptx` — Final presentation slides
- `README.md` — This file

## Submission
All work has been pushed to this repository. The notebook includes:
- Data loading and preprocessing
- Feature engineering (team form, scoring trend, home advantage)
- Model training and evaluation (Logistic Regression, Random Forest, XGBoost, MLP)
- Accuracy and F1 score comparison across models
